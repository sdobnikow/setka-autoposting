# Автопостинг Telegram @setkahhegor

300 постов, порядок сохранён. 10 в день, каждый час с 07:00 до 16:00 по Москве (cron `0 4-13 * * *` UTC). Один пост за запуск, не больше одного в часовой слот.

## Как работает
- `post.py` берёт пост с номером из `sent_count.txt`, отправляет в Telegram и только после подтверждения увеличивает счётчик и сохраняет его в репозиторий.
- `last_slot.txt` хранит последний занятый часовой слот: повторный или задержанный запуск в том же часу ничего не отправит.
- Ошибка Telegram: счётчик не меняется, следующий запуск повторит тот же пост.
- После 300-го поста отправка прекращается.

## Настройка
1. Settings → Secrets and variables → Actions → New repository secret: `TELEGRAM_BOT_TOKEN` (токен от BotFather). В чат и файлы не писать.
2. Settings → Actions → General → Workflow permissions → Read and write permissions → Save.
3. Actions → Telegram posts — 10 per day → Run workflow для теста (отправит следующий пост, если сейчас 07:00–16:59 МСК).

## Остановить
Создать в корне пустой файл `STOP`. Удалить файл, чтобы продолжить.

## Заменить очередь новой партией
1. Создать файл `STOP`.
2. Заменить `posts.json` (список строк JSON).
3. Проверить, что тексты целы, и только затем в `sent_count.txt` записать `0`.
4. Удалить `STOP`.
